# Security policy

## Supported versions

nixception is experimental. No version is officially supported; consider using
the latest release, or the latest commit on the `main` branch.

Note that nixception inherits most of its code from
[NativeLink](https://github.com/TraceMachina/nativelink) at the last
Apache-2.0 licensed upstream commit. Upstream security fixes published after
that point may not be present here; dependency-level security updates are
applied directly.

## Reporting a vulnerability

Prefer reporting vulnerabilities privately via
[GitHub security advisories](https://github.com/layus/nixception/security).

For vulnerabilities in the underlying NativeLink code that also affect the
upstream project, please also report them upstream at
<https://github.com/TraceMachina/nativelink/security>.
